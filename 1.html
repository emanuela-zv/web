O que é o HTML?

Ele é uma linguagem de marcação cujo objetivo é criar estruturas organizadas para web.

Não é considerado uma linguagem de programação, mas pode trabalhar junto de algumas, como CSS e java.

Desta forma, no HTML, se trabalha com tags.

Qual o papel do HTML na web?

Na web, o HTML tem função de organizar as informações, com o uso de suas tags, como <p >, que cria um parágrafo.
Dessa forma, sua função têm importância estética, visual e melhora na legibilidade dos conteúdos.

As principais tags utilizadas em textos são:

  • < p > : cria um parágrafo
  • < b > : deixa o texto em negrito
  • < i > : deixa o texto em itálico
  • < mark > : marca o texto em amarelo, como um marca-texto
  • < strong > : dá ênfase no texto e deixa estilizado em negrito
  • < em > : dá ênfase no texto e deixa estilizado em itálico
  • < span > : um parágrafo que recebe maior atenção do navegador
  • < br > : faz a quebra de linha
  • < hr > : cria uma linha vertical
