O que é uma regra CSS?

Uma regra CSS é uma forma criada para estilizar a página na web, a partir do uso de seletores, propriedades e valores.

Para um exemplo prático e simples temos como código: 


        (demais estruturas)

        <head>

        <style>
        #p1{
            color: red;
        }
        </style>

        </head>

        <body>

        <p id="p1"> Parágrafo com cor vermelha  </p>

        </body>

E como resultado, temos:

Parágrafo com cor vermelha

Desta forma, o # é o seletor. Ao utiliza-lo, define-se que será estilizado algum elemento que possua id (nesse caso, o id é p1), e o seletor define o que será estilizado.
Para estilizar classes, deve-se utilizar o . (ponto) como seletor e em seguida o nome dela.
Para tags, usa-se somente a tag como seletor.
Para estilizar tudo, de forma generalizada, usa-se o *;

Conforme o caso, a propriedade utilizada foi color e seu valor foi red. Ou seja, a propriedade é o que irá ser feito e o valor define como será feito, a forma como será estilizado.

Além disso, existem formas de estilizar um estado ou parte específica do seletor, como quando se passa o mouse por cima dele ou uma determinada linha do mesmo.
Para isso, podem ser usados:

  • Pseudo Classes
  • Pseudo Elementos
