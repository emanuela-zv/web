O que é uma regra CSS?

Uma regra CSS é uma forma criada para estilizar a página na web, a partir do uso de seletores, propriedades e valores.

Para um exemplo prático e simples temos como código: 


        (demais estruturas)

        <head>

        <style>
        #p1{
            color: red;
        }
        </style>

        </head>

        <body>

        <p id=1> Parágrafo com cor vermelha  </p>

        </body>

E como resultado, temos:

Parágrafo com cor vermelha

Desta forma, o #p1 é o seletor, o qual define o que será estilizado.
Neste caso, foi utilizado um id para o elemento parágrafo, por isso antes do nome do seletor, foi posto #.
Para estilizar classes, deve-se colocar . (ponto) antes do nome dela.

Conforme o caso, a propriedade utilizada foi color e seu valor foi red. Ou seja, a propriedade é o que irá ser feito e o valor define como será feito, a forma como será estilizado.

Além disso, existem formas de estilizar um estado específico do seletor, como quando se passa o mouse por cima do seletor ou uma determinada linha dele.
Para isso, podem ser usados:

  • Pseudo Classes
  • Pseudo Elementos
